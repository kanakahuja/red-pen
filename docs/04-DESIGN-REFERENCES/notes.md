## Design requirement
The evaluator experience should closely follow the referenced Figma design.
Inspect the Figma frame and local reference files before proposing UI changes.
Do not guess fonts, font sizes, colours, spacing, or component states.
Record the observed design tokens and any uncertainties in the audit report.
Do not edit the app during the audit.

## Details to capture
- Font family and available font weights
- Font sizes and line heights for headings, body, labels, and buttons
- Text colours, backgrounds, borders, and annotation colours
- Spacing, panel widths, button sizes, and corner radii
- PDF viewer layout and question/feedback panel behaviour
- Hover, selected, disabled, and error states
- Any team-specific differences for UPSC and Foundation
- Responsive behaviour, if represented
